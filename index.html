在 DSH 里添加 / Add it in DSH

  1. 打开 插件（Plugins） 页面，如未开启实验特性，先在 更多 → Experimental plugins 中打开 Custom plugin markets。
  2. 切到 发现（Discover） 标签页。
  3. 点击 Add index source（添加索引源），粘贴上面的地址并保存。
  4. 即可在发现页搜索、按分类/标签筛选、排序，并安装任意兼容版本。

添加后在 Host 侧核对：plugin_market list_indexes() 应返回本源的 URL 与标题。
